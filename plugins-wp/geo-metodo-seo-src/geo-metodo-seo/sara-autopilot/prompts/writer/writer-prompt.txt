REGRA CRÍTICA: PARÁGRAFOS CURTOS E ESCANEÁVEIS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Usuários leem em diagonal no celular. Parágrafos longos aumentam bounce rate.

REGRAS DE PARÁGRAFO:
- Cada <p> tem no MÁXIMO 3-4 linhas (60-80 palavras)
- NUNCA um <p> com mais de 100 palavras — divida em 2 parágrafos
- Entre parágrafos de texto denso, use <ul> ou <ol> para quebrar visualmente
- Uma ideia por parágrafo — se tiver 2 ideias, são 2 parágrafos
- Linha em branco visual entre parágrafos já vem do CSS do WordPress — não adicione <br>

REGRA CRÍTICA DE H2 E H3 — LEIA COM ATENÇÃO:
- Cada H2 tem MÍNIMO 150 e MÁXIMO 250-300 palavras abaixo dele
- NUNCA H2 com mais de 300 palavras — se precisar de mais, divida em 2 H2 separados
- NUNCA H2 sem parágrafo abaixo — é penalização de SEO
- H2 longo (mais de 200 palavras)? OBRIGATÓRIO pelo menos 1 H3 para dividir
- H2 com 3+ subtópicos? Use H3 para cada um — nunca coloque 3 subtópicos em parágrafos corridos
- H3 SEMPRE dentro de H2, nunca solto — nunca H4 ou H5
- Máximo 3 H3 por H2
- Use listas <ul>/<ol> quando listar 3+ itens seguidos dentro de um H2

3. Corpo com 5 a 7 seções H2:

Para cada parágrafo, escolha pelo menos UMA:

OBRIGATÓRIO — EXEMPLOS PRÁTICOS (regra de qualidade que o validador checa):
O artigo PRECISA conter pelo menos 2 exemplos práticos concretos, marcados de forma clara.
Use frases como "Por exemplo:", "Na prática:", "Um caso real:", "Imagine que você...".
Cada exemplo deve ser específico e aplicável — mostrar COMO fazer, não apenas dizer que é possível.
Artigos sem exemplos práticos são reprovados na auditoria de qualidade.

- "guia completo", "guia definitivo", "imperdível", "garantido"
